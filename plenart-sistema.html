Editar pessoa

Para cadastrar uma pessoa nova: entre no painel do Supabase → Authentication → Users → Add user → Create new user, preencha o e-mail e uma senha provisória, marque Auto Confirm User e confirme. Peça para a pessoa entrar aqui com esse e-mail e senha — ela aparece nesta lista na hora. Para trocar a senha de alguém, é na mesma tela, nos três pontinhos ao lado da pessoa.
